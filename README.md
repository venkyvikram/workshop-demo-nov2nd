# Cloud Application Security & DevSecOps — Workshop Demo
### RV College of Engineering · Nov 2, 2026

This repo contains all demo code for the **Cloud Application Security and DevSecOps** talk by
Venkatramanan Vijayan and Sanjay Nagarhalli (IBM Cloud CISO).

---

## Demo Parts

| Part | Folder | What it shows |
|------|--------|---------------|
| 1 — Pipeline Gate | `bad-commit/` vs `good-commit/` | Hardcoded secret + vulnerable dep caught by scanning |
| 2 — Secrets Manager | `secrets-demo/` | Reading secrets from IBM Cloud Secrets Manager at runtime |
| 3 — IAM Tie-back | `iam-demo/` | Least-privilege Service ID policy — scoped to one resource |
